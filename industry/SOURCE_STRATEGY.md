# 信号源策略 V0.1

目标不是“抓得最多”，而是尽量早地发现能转成江浙沪企业团建内容的信号。

## 三层信号

### A. 官方事实层（上游）
用途：发现营业、闭园、预约、交通、季节活动、新线路、新场景、安全风险等事实变化。
首批重点：
- 上海市文化和旅游局
- 浙江省文化广电和旅游厅
- 杭州文旅主管部门/官方文旅资讯
- 苏州市文化广电和旅游局
- 宁波文旅主管部门
- 湖州/安吉相关官方文旅
- 舟山相关官方文旅
- 各重点目的地/景区官方公开页面

原则：官方源不是因为“权威”就高分，而是因为它最早提供可执行事实。

### B. 用户需求层（最重要，逐步建设）
用途：知道 HR/行政到底在问什么。
来源优先级：
1. 真实客资/咨询中反复出现的问题（只提取匿名需求，不存个人信息）
2. 搜索联想、站内搜索词、公开问答
3. 已发布内容的评论问题
4. 历史高客资作品对应的问题结构

沉淀格式：地点 + 人数 + 预算/天数/玩法/季节/决策障碍。
示例：杭州 + 30人 + 预算300；上海 + 100人 + 年会场地；桐庐 + 2天1夜 + 雨天备选。

### C. 同行验证层
用途：确认哪些表达、玩法、目的地正在被市场生产和消费。
小红书/抖音同行继续看，但不再作为唯一选题源。
重点提取：新场地、新路线、新玩法、评论区真实问题、同一主题是否多人同时发布。
不做：看到爆款就原样跟发。

## 第一阶段规则
- 先接 10–30 个稳定公开源，不追求全网。
- 一个源连续两周没有产生有效候选，应降频或删除。
- 一个源经常产生 Top 5，应提高抓取频率。
- 付费/高维护抓取（公众号、小红书、抖音）暂缓，等官方层跑通后再接。
- 所有信号最终必须经过团建评分器，而不是直接进入生产。

## 真正的长期资产
最终最重要的信源不是某个网站，而是“真实客资问题库 + 已发布内容表现 + 同行验证 + 官方事实变化”的组合。
